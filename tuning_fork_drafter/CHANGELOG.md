# Changelog

## 0.1.5

* `mix tuning_fork.compose` plays the grid live on a stage, repeat by repeat, in place of a
  rendered bed; the settings line says which repeat is sounding.

## 0.1.4

* `mix tuning_fork.midi`: a MIDI keyboard in and heard, a pattern out with clock, both on
  one key strip, over `TuningFork.Midi.Monitor`.
* `TuningFork.LiveCodeApp` and `TuningFork.ComposerApp` take `:sink`, and the live app
  `:stage`, as the other apps do.

## 0.1.3

* Version brought level with the rest of the family; nothing else changed.

## 0.1.0

First release.
